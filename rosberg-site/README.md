# Rosberg — Portfólio Artístico

Site estático responsivo criado com HTML, CSS e JavaScript, baseado no portfólio PDF fornecido.

## Executar
Abra `index.html` no navegador, ou use um servidor local como `python -m http.server 8000` dentro da pasta e acesse `http://localhost:8000`.

## Publicar
Envie todo o conteúdo desta pasta (incluindo `assets`) para um serviço de hospedagem estática, como GitHub Pages, Netlify ou Vercel.

## Personalizar
- Textos e links: `index.html`
- Formação e espetáculos: `script.js`
- Estilo e responsividade: `style.css`
- Fotografias extraídas do PDF original: `assets/`
